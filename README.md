# 📌 Overview

**SS AI BotChat** is a modern AI-powered chatbot built using **Python**, **Streamlit**, and **Large Language Models (LLMs)**.

It provides an elegant ChatGPT-style interface while allowing users to interact with multiple AI models from a single application. The project focuses on clean UI, fast responses, modular architecture, and an intuitive user experience.

Whether you're learning AI, experimenting with LLMs, or building your own assistant, this project provides a strong starting point.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/sandilyashivshankar/SS_AI_BotChat.git
```

Move into the project

```bash
cd SS_AI_BotChat
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```

---

# 🔑 Environment Variables

Create a `.env` file

```env
MISTRAL_API_KEY=YOUR_API_KEY
HUGGINGFACE_API_KEY=YOUR_API_KEY
```
